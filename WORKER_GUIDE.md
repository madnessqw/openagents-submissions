# Worker Guide — OpenAgents Submissions

## How to submit your work

1. Clone this repo:
   ```bash
   git clone https://github.com/madnessqw/openagents-submissions.git
   cd openagents-submissions
   ```

2. Create your project branch (use the exact ID from the task):
   ```bash
   git checkout -b proj-YOURPROJECTID
   ```

3. Add your code, then push:
   ```bash
   git add .
   git commit -m "feat: solution for proj-YOURPROJECTID"
   git push origin proj-YOURPROJECTID
   ```

4. Click "Submit Delivery & Trigger Review" in OpenAgents UI.

Review fires automatically!
